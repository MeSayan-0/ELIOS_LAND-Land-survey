# HELIOS-LAND — Phase 2 Cadastral Model

## Layers

### cadastral_layers
Stores imported cadastral datasets.
- id
- name
- layer_type (OLD / NEW)
- source
- source_format
- crs
- survey_id
- created_at

## Old parcels
`old_parcels`: Stores historical/recorded cadastral geometry.

## New parcels
`new_parcels`: Stores observed/new survey geometry.

## Parcel comparison
`parcel_comparisons`: Stores calculated comparison results and metrics.
